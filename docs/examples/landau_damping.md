# Landau damping

`examples/Landau_damping.py` excites a Langmuir wave with $k\lambda_D \approx 0.5$ in a
warm electron plasma and follows its collisionless damping {cite}`landau1946`.

```{literalinclude} ../../examples/Landau_damping.py
:language: python
```

## Physics

The ions are made effectively immobile (`mass_over_proton_mass = 1e9`) and cold. For
a Maxwellian electron plasma the least-damped root of the dispersion relation
$1 + (k\lambda_D)^{-2}[1 + \xi Z(\xi)] = 0$, $\xi = \omega/(k v_{th})$, at
$k\lambda_D = $ {{ landau_k_lambda_D }} is
$\omega/\omega_{pe} = $ {{ landau_omega_theory }} $+$ {{ landau_gamma_theory }} $i$, so the
field energy should decay as $e^{2\gamma t}$ while oscillating at $2\omega_r$.

## Result of the script

```{figure} ../_static/figures/landau_damping_example.png
:width: 85%
:alt: Landau damping with the example parameters

Electrostatic energy for the parameters of the script. The fit through the maxima
gives $\gamma = $ {{ landau_example_gamma_measured }} $\,\omega_{pe}$, faster than the
linear rate. Generated by `docs/scripts/fig_landau_damping.py`.
```

The perturbation of the script is a displacement of amplitude $a = 0.025$ m in a box of
1 m, that is a density perturbation of relative amplitude
$ak = $ {{ landau_example_a_k }}. The bounce frequency of electrons trapped in the wave,
$\omega_b \approx \sqrt{ak}\,\omega_{pe} = $ {{ landau_example_bounce_over_wpe }} $\,\omega_{pe}$,
exceeds the linear damping rate, so the wave is in the trapping regime of O'Neil
{cite}`oneil1965`: the damping is initially faster than the linear prediction and the
oscillation frequency is shifted. The script prints the dominant frequency from
{func}`jaxincell.diagnostics` and compares it with the plasma frequency; for this run
it is {{ landau_example_dominant_frequency_over_wpe }} $\,\omega_{pe}$, with a frequency
resolution of $0.2\,\omega_{pe}$.

## Linear regime

To compare with linear theory the perturbation has to be small and the noise floor
lower than the signal after several e-foldings. The {doc}`../numerics/verification`
page does this with a quiet start built from `initial_positions` and
`initial_velocities`, $ak = $ {{ landau_quiet_a_k }} and {{ landau_quiet_particles }}
electrons, and finds $\gamma = $ {{ landau_gamma_measured }} $\,\omega_{pe}$ and
$\omega_r = $ {{ landau_omega_measured }} $\,\omega_{pe}$.
