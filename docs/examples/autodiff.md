# Gradient of a diagnostic

`examples/auto-differentiability.py` differentiates the time-averaged electric field
with respect to the electron drift speed and compares the result with one-sided
finite differences of decreasing step.

```{literalinclude} ../../examples/auto-differentiability.py
:language: python
```

The differentiable quantity is a function of the runtime input dictionary passed to
`sim.run`; everything else about the simulation is fixed when the `Simulation` object
is built. `jax.grad` compiles a reverse-mode program on the first call.

```{figure} ../_static/figures/autodiff.png
:width: 100%
:alt: Automatic differentiation against finite differences

(a) The time-averaged field as a function of the drift speed with the tangent from
the JAX gradient, $d\langle E_x\rangle/dv_d = $ {{ autodiff_gradient_jax }} V s/m². (b)
Finite differences approach the gradient for intermediate steps and are dominated by
round-off for small ones and by curvature for large ones; the closest is
{{ autodiff_best_finite_difference }} at $\epsilon = $ {{ autodiff_best_epsilon }} m/s.
The first gradient evaluation took {{ autodiff_grad_time_first_s }} s including
compilation, subsequent ones {{ autodiff_grad_time_warm_s }} s. Generated by
`docs/scripts/fig_autodiff.py`.
```

The mean field is a noisy function of the drift because it sums the contributions of
a finite number of particles. Panel (a) shows the consequence: the trend of the
objective across the scan is flat, while its local slope, which is what the gradient
and the small-step finite differences measure, is much steeper. The gradient is the
exact derivative of the discrete simulation, noise included. For an optimisation
choose an objective that averages the noise away, such as a fitted growth rate or a
time-averaged energy, as the {doc}`optimisation` and {doc}`inference` examples do.
