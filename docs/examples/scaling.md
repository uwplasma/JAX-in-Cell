# Timing and scaling

`examples/scaling_energy_time.py` measures wall-clock time and maximum relative
energy error as the number of grid points, the number of particles, the number of
steps and the time step are increased by a factor 1.5 four times. Each configuration is
a new compilation, so the script first runs one warm-up simulation.

```{literalinclude} ../../examples/scaling_energy_time.py
:language: python
:lines: 1-60
```

The figure below is the equivalent measurement made for this documentation, timed
after compilation on the build machine.

```{figure} ../_static/figures/scaling.png
:width: 100%
:alt: Wall-clock time against particle count, grid size and number of steps

Wall-clock time of the explicit scheme against the number of particles, of grid
points and of time steps, measured on the {{ scaling_device }} that built this
documentation ({{ scaling_cpu }}, JAX {{ scaling_jax_version }}). Generated by
`docs/scripts/fig_scaling.py`.
```

The time grows linearly with the number of steps and, once the particle count is
large enough to amortise the per-step overhead, linearly with the number of
particles. It also grows with the number of cells, because the deposition evaluates
the shape function of every particle on the whole grid; the cost scales with the
product of particles and cells. See {doc}`../user_guide/performance`.
