# Two-stream instability

`examples/two-stream_instability.py` reads `examples/input.toml`, runs it, and
animates the result. It is the configuration used throughout the
{doc}`../getting_started/first_simulation` tutorial.

```{literalinclude} ../../examples/two-stream_instability.py
:language: python
```

## Physics

Two electron beams of equal density drift through each other at $\pm v_d = \pm0.2c$
with thermal speed $v_{th} = 0.05c$, in a proton background of equal temperature. The
cold-beam dispersion relation
$1 = \tfrac12\omega_{pe}^2[(\omega - kv_d)^{-2} + (\omega + kv_d)^{-2}]$ has a purely
growing root for $k v_d < \omega_{pe}$; the box length is chosen so that the first mode
has $k v_d/\omega_{pe} = $ {{ two_stream_k_vd_over_wpe }} and $k\lambda_D = $ {{ two_stream_k_lambda_D }},
at the edge of the cold-beam instability band, where the thermal spread decides the
growth rate {cite}`buneman1959,oneil1968`. The instability saturates when the beams
are trapped in the wave and phase space rolls up into a vortex.

linear phase is shorter, and the rate fitted over it is less reliable. See

## Variations

* `time_evolution_algorithm = 1` switches to the implicit scheme; the
  {doc}`energy_conservation` page compares the two on this problem.
* Set `particle_BC_left = particle_BC_right = 1` and the same for the fields to put
  the beams between reflecting walls.
* `relativistic = true` uses the relativistic pusher; at $0.2c$ the difference in
  growth rate is at the percent level.
