# Governing equations

## Vlasov-Maxwell system

Each species $s$ of a collisionless plasma is described by a distribution function
$f_s(\mathbf x, \mathbf v, t)$ that obeys the Vlasov equation,

```{math}
\frac{\partial f_s}{\partial t}
+ \mathbf v\cdot\nabla f_s
+ \frac{q_s}{m_s}\left(\mathbf E + \mathbf v\times\mathbf B\right)\cdot\nabla_{\mathbf v} f_s = 0 ,
```

coupled to Maxwell's equations for the fields generated by the plasma itself,

```{math}
\frac{\partial \mathbf B}{\partial t} = -\nabla\times\mathbf E, \qquad
\frac{\partial \mathbf E}{\partial t} = c^2\nabla\times\mathbf B - \frac{\mathbf J}{\epsilon_0}, \qquad
\nabla\cdot\mathbf E = \frac{\rho}{\epsilon_0}, \qquad
\nabla\cdot\mathbf B = 0,
```

with the charge and current densities

```{math}
\rho = \sum_s q_s\int f_s\,d^3v, \qquad
\mathbf J = \sum_s q_s\int \mathbf v f_s\,d^3v .
```

The two divergence equations are constraints: if they hold initially and the sources
satisfy the continuity equation $\partial_t\rho + \nabla\cdot\mathbf J = 0$, the two
evolution equations preserve them. The explicit scheme relies on this property through
its charge-conserving current deposit; see {doc}`explicit` and {doc}`field_solvers`.

## The 1D3V reduction

JAX-in-Cell keeps all three components of $\mathbf v$, $\mathbf E$ and $\mathbf B$
but lets them depend on one spatial coordinate only, $x$, with
$\partial_y = \partial_z = 0$. The curl reduces to

```{math}
\nabla\times\mathbf F = \left(0,\; -\frac{\partial F_z}{\partial x},\; \frac{\partial F_y}{\partial x}\right),
```

so that $B_x$ is constant in time (it can only be set externally), $E_x$ is driven by
$J_x$ alone,

```{math}
\frac{\partial E_x}{\partial t} = -\frac{J_x}{\epsilon_0}, \qquad
\frac{\partial E_x}{\partial x} = \frac{\rho}{\epsilon_0},
```

and the transverse components form two decoupled electromagnetic systems
$(E_y, B_z)$ and $(E_z, B_y)$,

```{math}
\frac{\partial E_y}{\partial t} = -c^2\frac{\partial B_z}{\partial x} - \frac{J_y}{\epsilon_0}, \quad
\frac{\partial B_z}{\partial t} = -\frac{\partial E_y}{\partial x}, \qquad
\frac{\partial E_z}{\partial t} = c^2\frac{\partial B_y}{\partial x} - \frac{J_z}{\epsilon_0}, \quad
\frac{\partial B_y}{\partial t} = \frac{\partial E_z}{\partial x}.
```

Electrostatic problems (Langmuir waves, Landau damping, two-stream and bump-on-tail
instabilities) live entirely in $E_x$. Electromagnetic problems (the Weibel
instability, light waves, magnetised plasmas with an external $B_x$) involve the
transverse pairs. Particles keep their $y$ and $z$ coordinates, which only serve to
apply periodic wrapping and have no effect on the fields.

## Particle discretisation

The distribution function of species $s$ is represented by $N_s$ pseudo-particles,
each standing for $w_s$ physical particles:

```{math}
f_s(x, \mathbf v, t) \approx w_s\sum_{p=1}^{N_s} S\!\left(x - x_p(t)\right)\,\delta\!\left(\mathbf v - \mathbf v_p(t)\right),
```

where $S$ is the shape function of finite width that gives the pseudo-particle a
charge cloud of width $\sim\Delta x$ rather than a point charge. Substituting into the
Vlasov equation shows that $f_s$ is a solution when every pseudo-particle follows a
characteristic,

```{math}
\frac{d x_p}{dt} = v_{x,p}, \qquad
\frac{d \mathbf v_p}{dt} = \frac{q_s}{m_s}\left(\mathbf E(x_p) + \mathbf v_p\times\mathbf B(x_p)\right),
```

with the fields evaluated at the particle through the same shape function. In the
relativistic version the momentum $\mathbf p = \gamma m\mathbf v$ replaces the velocity
on the left-hand side, with $\gamma = (1 - v^2/c^2)^{-1/2}$.

The sources on the grid follow from the same representation:

```{math}
\rho(x_i) = \sum_s q_s w_s\sum_p S(x_i - x_p), \qquad
\mathbf J(x_i) = \sum_s q_s w_s\sum_p \mathbf v_p\, S(x_i - x_p),
```

although the longitudinal current is not deposited with this formula but from the
continuity equation, as described in {doc}`explicit`.

## Collisions

The Vlasov equation above describes a collisionless plasma. Setting
{class}`~jaxincell.Collisions` puts a Landau collision operator on its right-hand
side,

```{math}
\left(\frac{\partial f_s}{\partial t}\right)_{c}
= \sum_{s'}\frac{q_s^2 q_{s'}^2 \ln\Lambda}{8\pi\epsilon_0^2 m_s}
\frac{\partial}{\partial \mathbf v}\cdot\!\int d^3v'\,
\frac{u^2 \mathbb I - \mathbf u\mathbf u}{u^3}
\left(\frac{1}{m_s}\frac{\partial}{\partial\mathbf v} - \frac{1}{m_{s'}}\frac{\partial}{\partial\mathbf v'}\right)
f_s(\mathbf v) f_{s'}(\mathbf v'),
```

with $\mathbf u = \mathbf v - \mathbf v'$, represented by the binary Monte Carlo
scheme of {doc}`collisions`.

## What is not included

There is no ionisation or recombination, no radiation reaction, no particle source
and no field ionisation. Fields are functions of $x$ only, so $B_x$ can only be
imposed externally and is constant in time. Gravity and forces other than the
Lorentz force are not available.
